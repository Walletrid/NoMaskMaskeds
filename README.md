# NoMaskMaskeds

At first, I wanted to make a mod that just removed Masked's masks, but after finishing it, I thought: Why not let you customize every single thing that is even slightly related to the masks? So now, the mod does NOT do just this :c

If you have any other mod that already does this, I'd recommend not using this one, since it'd be pointless.
