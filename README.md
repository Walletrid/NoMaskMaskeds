# NoMaskMaskeds

I remember looking around Thunderstore and not finding a simple and convenient mod to remove these dudes masks, so I thought: Why not make a mod that does literally JUST this.

If you have any other mod that already does this, I'd recommend not using this one, since it'd be pointless.
